# 🏎️ F1 Teams Creator

A browser-based Formula 1 team builder where you design your own custom racing team, assign drivers, and give each one unique skills or flaws that affect their performance on the track.

## 🚀 Live Demo

> Open `index.html` in your browser — no build step required.

## ✨ Features

- Create and name your own Formula 1 team
- Add drivers with customizable attributes
- Assign special **skills** (advantages) or **flaws** (disadvantages) to each driver
- Interactive UI built with vanilla JavaScript

## 🛠️ Tech Stack

| Layer    | Technology        |
|----------|-------------------|
